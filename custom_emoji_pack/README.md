# АУТЕНТИЧНЫЙ ЭМОДЗИ-ПАК «СИЛА И ЧЕСТЬ» (BRAND IDENTITY SET)

Фирменный набор из 12 кастомных эмодзи в формате **100×100 PNG (RGBA, прозрачный фон)**, отрисованный **точь-в-точь по реальным исходникам, вещам первого дропа и физическим ассетам бренда**.

Типографика обновлена: нагрудный знак использует точный контур референса, остальные надписи — локальную гарнитуру Sila Chest. ZIP и preview grid пересобраны из тех же файлов; загрузка нового набора в Telegram отдельно не выполнялась.

## 3. Регистрация набора в Telegram за 2 минуты

1. В Telegram перейдите в официального бота: **`@Stickers`**.
2. Отправьте команду:  
   `/newemojipack`
3. Выберите тип:  
   **`Static emoji`**
4. Введите название:  
   `СИЛА И ЧЕСТЬ · Мерч`
5. Отправляйте боту файлы из папки `icons/` **как документ/файл**:
   - `01_sword.png` → в ответ отправьте ⚔️
   - `02_seal.png` → в ответ отправьте 🛡️
   - `03_drop.png` → в ответ отправьте 👕
   - и далее по таблице выше.
6. Введите команду:  
   `/publish`
7. В качестве обложки набора загрузите `02_seal.png` (или нажмите `/skip`).
8. Задайте короткую ссылку на латинице (например, `sila_chest_merch`).  
   Бот вернет готовую ссылку: `https://t.me/addemoji/sila_chest_merch`.
