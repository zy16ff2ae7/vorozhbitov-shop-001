## 2. Инструкция: Как создать пак в Telegram за 2 минуты (Бесплатно)

1. Откройте в Telegram официального бота: **`@Stickers`**.
2. Отправьте команду:  
   `/newemojipack`
3. На вопрос о типе выберите:  
   **`Static emoji`**
4. Введите название набора, например:  
   `Сила и Честь · Меню`
5. Поочерёдно отправляйте боту файлы из папки `icons/`:
   - Бот просит файл — прикрепите `01_sword.png` **как файл / документ** (не как сжатое фото!).
   - Бот спрашивает эмодзи — отправьте ⚔️.
   - Повторите для остальных иконок из таблицы выше.
6. Когда отправите все 12 файлов, введите команду:  
   `/publish`
7. На вопрос об иконке набора (`Set icon`) можно отправить `02_seal.png` или нажать `/skip`.
8. Задайте короткую ссылку набора латиницей, например:  
   `sila_i_chest_pack`
9. Бот пришлёт готовую ссылку вида:  
   `https://t.me/addemoji/sila_i_chest_pack`

## 3. Как применить в коде бота (`bot.py`)

1. Добавьте созданный пак к себе в Telegram по ссылке `t.me/addemoji/...`.
2. Напишите созданные эмодзи в любой чат (или в «Избранное»).
3. Скопируйте эмодзи в буфер обмена как обычный символ и вставьте в текст кнопок в коде:

```python
markup = {
    "inline_keyboard": [
        [
            {"text": "⚔️ ПЕРВЫЙ ДРОП", "callback_data": "catalog"},
            {"text": "📦 МОИ ПОКУПКИ", "callback_data": "orders"}
        ],
        [
            {"text": "🪪 КАБИНЕТ", "callback_data": "profile"},
            {"text": "💬 ПОДДЕРЖКА", "callback_data": "support"}
        ],
        [
            {"text": "🛒 ОФОРМИТЬ ЗАКАЗ", "callback_data": "checkout"}
        ],
        [
            {"text": "⬅️ ГЛАВНОЕ МЕНЮ", "callback_data": "menu"}
        ]
    ]
}
```

*При отображении у пользователя Telegram автоматически подставит фирменные цветные векторные иконки прямо в кнопки.*
