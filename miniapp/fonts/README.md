# Sila Chest

Локальная кириллическая гарнитура интерфейса и новых медиаподписей.

- `sila-chest-400.woff2` — Regular;
- `sila-chest-700.woff2` — Bold;
- `SilaChest-OFL.txt` — исходное авторское право и полная лицензия SIL OFL 1.1.

Гарнитура является изменённой производной **Cormorant SC** (Cormorant Project Authors): контуры и метрики горизонтально масштабированы до 72%, семейство переименовано в **Sila Chest**. Это проверенное свободное стилевое приближение к присланному референсу, а не утверждение, что исходное название шрифта установлено.

Отдельный файл `../assets/brand/sila-chest-wordmark.png` содержит точные контуры надписи «СИЛА И ЧЕСТЬ», извлечённые из исходного референса `task_materials/chat_export/photos/photo_2@24-10-2026_14-19-10.jpg`. Он используется как графический wordmark и не подменяет наборную гарнитуру для остальных текстов.

Старые Manrope/Unbounded сохранены как исходные файлы, но больше не подключаются интерфейсом.
