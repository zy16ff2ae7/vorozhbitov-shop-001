# Ворожбитов 2.0 — анимация подписки

Исходники последнего согласованного варианта с аватаркой канала: вертикальная версия для Shorts и горизонтальная для видео. Рядом лежат предпросмотры. Полный набор всех версий и исходные файлы доступны в приложении к релизу `motion-cta-20261027`.

Для сборки нужны Node.js, Python 3 и FFmpeg с кодеками ProRes 4444 и H.264.

```sh
cd motion-cta
npm install
npm run build
```

Файлы появятся в `rendered/`: прозрачный ProRes, зелёный фон и предпросмотр. Длительность 6 секунд, аудио нет. При необходимости путь к FFmpeg задаётся переменной `FFMPEG`. Кнопки на видео являются графической анимацией.
