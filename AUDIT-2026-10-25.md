# Аудит проекта — 56 находок (2026-10-25)

Метод: чтение кода (bot.py, payments.py, miniapp/*), проверка каталога скриптом,
прогон тестов (214 Python OK, validate_release OK, Node 16/16, check_ui 15/15),
HTTP-проверки preview-сервера, инвентаризация ассетов и репозитория.
Справедливости ради: ядро сделано крепко — HMAC-валидация initData со сроком,
подписи вебхуков, идемпотентность заказов (UNIQUE request_id), rate-limit,
экранирование в шаблонах, WAL+busy_timeout. Проблемы — вокруг этого ядра.

## Критичные / высокие

1. **Нет учёта остатков вообще.** Ни в каталоге, ни в БД нет количества по размерам:
   `available()` = «есть хоть один размер в списке» (`miniapp/shop-core.js:53-57`).
   «Первый тираж», «Осталось мало» — только текст `stock_label`. Любой размер можно
   продать бесконечное число раз; единственный реальный лимит — серийники подарка.
2. **Дроп-гейт fail-open при битой дате.** `parse_drop_moment` при ошибке парсинга
   возвращает None → сервер считает окно открытым (`bot.py:134-159`); клиент так же
   (`dropMode`, `valid()`). Опечатка в `starts_at` молча открывает продажи раньше срока.
3. **Offset getUpdates только в памяти.** Рестарт бота переобрабатывает накопившиеся
   апдейты Telegram — риск дублей действий из нативного меню (`polling_loop`, offset=0).
4. **Slowloris / исчерпание потоков.** ThreadingHTTPServer без лимита потоков и без
   таймаута чтения тела: медленный клиент держит поток бессрочно (`rfile.read`).
5. **Весь `miniapp/` (148 МБ, 371 файл, из них 93 МБ видео) — публичный веб-корень.**
   Неиспользуемые ролики кампаний, исходная бетонная PNG 2.4 МБ, старые hero v1/v2,
   исходники фото — всё скачивается кем угодно и всё попадает в Docker-образ.
6. **HTTP/1.0 и нет сжатия.** BaseHTTP без gzip/br и keep-alive: index+CSS+JS ≈ 290 КБ
   сырого текста с `no-cache` на каждое открытие, каждый ассет — новое соединение.
7. **~3.5 МБ до входа в магазин.** Welcome-видео 2.4 МБ (`preload=auto`), шрифты 240 КБ,
   hero ~0.5 МБ, JS/CSS ~0.3 МБ — первый экран тяжёлый для мобильной сети.
8. **Клуб: рассинхрон дня и потеря офлайн-отметок.** Клиент считает «сегодня» по TZ
   устройства (`localDateISO`), сервер — по Europe/Moscow: streak и кнопка врут вне
   московского пояса. Отметка при ошибке POST пишется локально и никогда не досылается;
   следующий успешный GET может её стереть серверным состоянием.
9. **CSP без frame-ancestors / нет X-Frame-Options.** Витрину можно встроить в любой
   сайт (кликджекинг). Telegram нужен точечный `frame-ancestors`, а не пустота (`_csp`).
10. **CSP `img-src https:` + `style-src 'unsafe-inline'`.** Любые внешние картинки
    разрешены — трекинг/подмена при компрометации каталога.

## Бэкенд — средние

11. **RateLimiter при заполнении max_keys=4096 отклоняет всех новых** (`bot.py:58-90`):
    флуд мусорными IP-ключами на `/api/catalog` блокирует легитимных пользователей.
12. **RateLimiter: отклонённый ключ не обновляет порядок/очистку** — префиксная чистка
    OrderedDict опирается на порядок последних *принятых* хитов; «горячие» старые
    ключи могут жить дольше окна.
13. **Жёсткий лимит тела JSON 8192 байта** (`bot.py:7342`): длинный адрес/комментарий
    + полная корзина → отказ в разборе без понятной причины для пользователя.
14. **Статика читается целиком в RAM на каждый запрос** (PNG по 2.4–2.7 МБ), нет
    ETag/If-Modified-Since: при `max-age=3600` картинки потом перекачиваются полностью.
15. **Шрифты — immutable на год по неизменным именам.** Спасение только в `_stamp_fonts`;
    устаревший CSS из кеша Telegram навсегда застрянет на старой версии шрифта.
16. **`/api/catalog` на каждый запрос** статит десятки файлов (`_stamp_media` по всем
    продуктам) и хэширует шрифты чтением файлов (`bot.py:7887`) — лишняя работа без кеша.
17. **Нет top-level обработчика исключений в do_GET/do_POST**: необработанная ошибка
    рвёт соединение без HTTP-ответа — WebView показывает пустоту, трейс только в stderr.
18. **Server header раскрывает стек**: `BaseHTTP/0.6 Python/3.11.2`.
19. **Цена — строка «4 900 ₽», два парсера** (strict + оставшийся мягкий
    `parse_price_rub`, `payments.py:63`): контракт цены дублируется клиентом и сервером
    вручную; мягкий парсер — мина при случайном использовании.
20. **Свой load_dotenv** без `export`, экранирования и `#` внутри значений: часть
    легитимных .env молча исказится (`bot.py:162`).
21. **compose: `env_file required: false`** — при потерянном .env ошибка конфигурации
    обнаружится поздно, а не на старте контейнера.
22. **Python 3.13 в Docker против 3.11 в CI** — тесты гоняются не на прод-рантайме.
23. **Два источника правды каталога**: корневой `catalog.json` запекается в образ,
    рабочий на сервере — `data/catalog.json` (по README). Обновления требуют ручной
    синхронизации ключей (уже приводило к рассинхрону hero).
24. **Бэкапы БД и каталога лежат в том же томе `data/`**, без шифрования и выноса:
    потеря тома = потеря данных вместе с бэкапами; внутри — ПДн клиентов.
25. **Rate-limit по IP за прокси**: без `trusted_proxy_ips` все клиенты за реверс-прокси
    делят один ключ (IP прокси) — суммарный лимит каталога 60/мин на всех.

## Фронтенд — средние и мелкие

26. **Опрос оплаты каждые 4 с без предела** по времени и попыткам и без паузы на скрытой
    вкладке; один `payWatchId` — второй счёт перестаёт отслеживаться (`app.js:948-965`).
27. **Видеосцена фильма всегда 9000 мс**, ролик белой — 10.13 с: концовка вращения
    обрезается; длительность не читается из метаданных (`app.js:1888`).
28. **Фильм не предзагружает следующую сцену** — на медленной сети чёрные кадры при смене.
29. **Дроп в текущем конфиге мёртв**: все даты пусты → вечное «ДРОП ОТКРЫТ», таймер
    никогда не виден, награда клуба (ранний доступ) ничего не даёт.
30. **CTA «СВОИ» ведёт в никуда без `support_username`** (`managerUrl`="") — мёртвая
    кнопка при незаполненной конфигурации; секция при этом показывается.
31. **Согласие на обработку ПДн без политики**: ссылка «Политика» скрыта, пока не задан
    `privacy_url` (в каталоге его нет) — чекбокс есть, документа нет (`index.html:476`).
32. **Два `<h1>` в DOM** (welcome + hero) — семантика и доступность.
33. **Точки галереи 7×7 px** (активная 18×7) — цели касания в разы меньше минимума 44px
    (`styles.css:948`).
34. **44 правила font-size 8–9px**: подписи, факты и паспорт набраны ниже комфортного
    минимума мобильного UI.
35. **Весь UI — декоративным serif**: `--font-ui` == `--font-display` («Sila Chest»);
    поля ввода, цифры и мелкий текст в акцидентном шрифте (`styles.css:33-34`).
36. **Manrope и Unbounded (5 файлов, ~286 КБ) лежат в `fonts/`, но @font-face их не
    подключает** — мёртвый груз; при этом удобочитаемого UI-шрифта как раз нет.
37. **Нет srcset/responsive-изображений**: на экран 360px отдаются те же 900–1080px
    картинки; спин белой — 8 кадров ≈ 3.1 МБ на открытие карточки.
38. **Локальная копия Telegram SDK (117 КБ) грузится всегда** и устаревает без
    обновлений; `viewer3d.js` тянется даже там, где 360° нет.
39. **localStorage без версионирования схемы**: `cleanCart` молча выбрасывает и сливает
    позиции и режет корзину `slice(0,20)` — потери без уведомления пользователя.
40. **Pending-checkout в localStorage общий на устройство** (`owner=""` по умолчанию,
    `checkout.js:69`): чужой отпечаток/request_id может унаследоваться вторым аккаунтом.
41. **Поиск без debounce** перерендеривает сетку на каждый символ; шаблон поиска
    включает `undefined` для отсутствующих полей — запрос «undefined» найдёт такие товары.
42. **Размерная сетка продублирована**: `SIZE_GUIDE` в shop-core.js и статичная таблица
    в разметке — рассинхрон при правке в одном месте.
43. **`recommendSize`: подсказка «между размерами» считается от лучшего score**, а не
    от размера после сдвига fit (close/oversize) — пограничный совет может врать.
44. **Цена «от …» допускается парсером и становится точной суммой** в корзине и счёте —
    семантическая мина (`shop-core.js:42`, `payments.py` STRICT_PRICE_RE).
45. **Текстовые глифы вместо иконок**: «Ⅱ» (U+2161), «▶», «↑» — риск тофу/разного
    рендера (битый глиф в паспорте уже ловили на практике).
46. **Фокус в модалках**: trap только по Tab на краях; после blur в фильме скринридер
    теряет место; Escape закрывает модалку поверх незавершённого ввода без подтверждения.
47. **Запечённая контактная тень hero «плывёт» при параллаксе**: bg-слой (scale 1.05)
    и фигура (1.012) смещаются по-разному — тень отделяется от тела на скролле.
48. **Тост перекрывает поля checkout** на узких экранах (fixed поверх формы) — закрывает
    поле ввода в момент заполнения.
