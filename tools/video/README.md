# Ролики выпуска — как пересобрать

## Что использует витрина сейчас

В `catalog.json` выбран исходный `assets/video/teaser.mp4`. Его финал сохранён.
Приветствие использует статичный `tee-gym-final.jpg`; фоновое видео выключено
через `welcome_motion: false`. Новая миниатюра — `teaser-thumbnail-final.jpg`.
Это обновление изображений и интерфейса, а не новый ролик с движущимся человеком.

Версии v3/v4 ниже — архив экспериментов, отклонённых при просмотре. Не подключать
их автоматически вместо исходного фильма. Сценам с реальным движением тела нужен
отдельный видеогенератор или съёмка; обычный монтаж неподвижных кадров этого не даёт.

## Экспериментальная версия v4 — не используется

`make_video_v4.py` собирает 31,2 секунды / 936 кадров при 30 fps. Девять сцен:
световой след → ночь → крыша → зал → подтягивание со спины → крупный план
ткани и постоянной детали → группа → герой → анимированная монограмма и меч.
Финал занимает 7,2 секунды, начинается на 24,0 с. Пропорции фото сохраняются;
зал, крыша, группа и полный задний кадр вписаны целиком. Человек в кадре
не анимируется: движение создают камера, свет, титры и композиция.

Готовые файлы: мастер 1080×1920 (10,22 МБ), мобильная версия 720×1280
(2,54 МБ), бесшовная заставка 810×888 / 8 с (1,02 МБ) без звука.
Всё — H.264, yuv420p, faststart. Мастер сохраняется в `--output`, в миниапп
попадает только мобильная версия с постерами и превью Telegram 180×320.
Мастер содержит новый AAC-микс: музыкальная основа исходника до 24-й секунды
и отдельное завершение с резонансом металла и низким ударом. Звук не является
побитовой копией исходной дорожки. Измеренная мобильная версия: −16,35 LUFS,
true peak −1,33 dBTP.

Нужны Python 3.10+, `numpy`, `pillow`, `ffmpeg`, `ffprobe`. Шрифты и OFL-лицензии
находятся в `tools/video/fonts/`; они скопированы из исходного видеопроекта.

```sh
python3 tools/video/make_video_v4.py --output /absolute/path/video-v4 --previews
python3 tools/video/make_video_v4.py --output /absolute/path/video-v4
```

`--assets` и `--fonts` позволяют явно указать другие каталоги. Выходной каталог
должен отличаться от `assets/video`. Скрипт сначала рендерит временные файлы,
проверяет формат, длительность, число кадров, звук, размер и faststart,
затем заменяет файлы с новыми именами v4. Старые версии остаются на месте.
Между запусками нельзя менять исходные изображения.

Новые исходники: `assets/drop/tee-detail-v4.png` и `assets/brand/monogram-v4.png`.
У монограммы RGB-фон с шахматным рисунком: это входной файл композитора,
не готовый прозрачный логотип для сайта. Рендерер выделяет светлую тёплую
фигуру в альфа-маску и проверяет её; шахматный фон в видео не попадает.
JPEG `tee-detail-v4.jpg` используется как седьмое фото товара.

Исходники лицензий: [Ruslan Display](https://raw.githubusercontent.com/google/fonts/main/ofl/ruslandisplay/OFL.txt),
[Oswald](https://raw.githubusercontent.com/google/fonts/main/ofl/oswald/OFL.txt).

## Экспериментальная версия v3 — не используется

`make_video_v3_corrected.py` использует обновлённые фотографии футболки и модели
из `miniapp/assets/drop/` и `miniapp/assets/spin/`. Старые файлы сохранены.
Тизер: 917 кадров, 30 fps, 720×1280, до 6 МБ, исходная AAC-дорожка из
`assets/video/teaser.mp4` копируется без перекодирования и сверяется по хешу.
Заставка: 378 кадров, 30 fps, 810×888, без звука, замкнутые переходы.
Финал использует исправленный задний вид изделия. Текущие фотографии:
`tee-night-v7.jpg`, `tee-crew-v3.jpg`, `tee-roof-v3.jpg`, `tee-gym-v3.jpg`,
`tee-back-v3.jpg`. Кадр с подтягиванием вписывается целиком: в тизере и заставке
сохраняются кисти, ступни, кружка с монограммой и надпись на стене.

Нужны Python с `numpy`/`pillow`, `ffmpeg`, `ffprobe` и каталог со шрифтами
`RuslanDisplay.ttf`, `Oswald-Regular.ttf` из исходного видеопроекта.

```sh
python3 tools/video/make_video_v3_corrected.py --font-dir /path/to/video/fonts --check-inputs
python3 tools/video/make_video_v3_corrected.py --font-dir /path/to/video/fonts
```

`--welcome` пересобирает только заставку, `--teaser` — только тизер.
Вывод версионирован: `teaser-v3.mp4`, `welcome-loop-v3.mp4`, постеры и
`teaser-thumbnail-v3.jpg` (180×320 для Telegram); `welcome-v3.jpg` лежит в assets.
Ограничение потоков и пониженный приоритет уменьшают нагрузку. Готовые файлы
переносятся из временного каталога после проверки длительности, размера и звука.
Для одновременного вывода заставки и фото `--output-dir` должен быть на том же
томе, что и `--assets-dir`.

## Исходный тизер v2

`miniapp/assets/video/teaser.mp4` собран скриптом `make_video_v2_film.py`
(взят из `zy16ff2ae7/vorozhbitov-clothing-bot-sila-i-chest`, путь
`sila-i-chest/video/make_video_v2_film.py`) — это генератор, а не монтаж в редакторе:
каждый кадр рисуется в PIL и пишется в ffmpeg через пайп.

## Что делает
1080×1920, 30 fps, 30.6 с, 13 сегментов:
интро «ВОРОЖБИТОВ ПРЕДСТАВЛЯЕТ» → 8 сцен с титрами → срыв кадра в проекторе →
стробо-нарезка ч/б → длинный герой-кадр → флэтлей «ДВА ПРИНТА» → финал с мечом и ВВ.

Плёночный грейд: bleach bypass, тёплые света, холодные тени, зерно, дрожание кадра,
мерцание экспозиции, царапины, пыль, засветки. Звук синтезируется в скрипте:
барабан, хор-пад, ветер, стрёкот проектора, наковальня, «шинг» меча.

Титры набраны уставом — тем же строем букв, что и принт на груди
(`ruslan.woff2` из доноpа, сконвертирован в TTF через fontTools).

## Зависимости
`numpy`, `pillow`, `scipy`, `imageio-ffmpeg`.

## Запуск
Скрипт ждёт рядом с собой (на уровень выше `video/`) 10 фото
`sila-i-chest-NN-*.jpg` и шрифты в `video/fonts/`:
`RuslanDisplay.ttf`, `Oswald-Regular.ttf`.

```
python3 video/make_video_v2_film.py     # ~4 мин, отдаёт 1080×1920, ~32 МБ
```

Витринная версия — 720×1280, чтобы не жечь мобильный трафик:

```
ffmpeg -y -i sila-i-chest-teaser-v2-film.mp4 -vf "scale=720:1280:flags=lanczos" \
  -c:v libx264 -preset slow -crf 26 -pix_fmt yuv420p -profile:v high -level 4.0 \
  -c:a aac -b:a 96k -ac 2 -movflags +faststart miniapp/assets/video/teaser.mp4
```

Постер: `ffmpeg -ss 22.2 -i teaser.mp4 -frames:v 1 -vf scale=540:-2 teaser-poster.jpg`

## Правка сценария
Список `SHOTS` в начале файла: `(файл, титр, секунды, фокус, движение)`.
Титры приведены к тем кадрам, что реально есть в проекте, — если меняете
фото, поменяйте и титр, иначе над крышей окажется «ВЕРНОСТЬ».
