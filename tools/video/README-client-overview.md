# Видеообзор для заказчика

Создан по запросу на самостоятельный видеофайл, без публикации Telegram-бота или внешнего демостенда.

## Файл

`ui-checks/client-overview/vorozhbitov-bot-overview.mp4`

- 1920 × 1080, 25 fps, H.264 + AAC, MP4 fast-start.
- Продолжительность текущего выпуска — 3:56; примерно 34 МБ.
- Русские поясняющие титры, подсветка нажатий, оригинальный тихий музыкальный фон. Дикторской озвучки нет.
- Встроенные главы, обложка `cover.jpg` и технический `video-report.json` рядом.
- Показан браузерный симулятор с настоящими обработчиками бота, не работа боевого Telegram. Данные, платежи, доставка и пересчёт склада в записи явно тестовые.

## Что показано

Поиск → отдельное согласие на избранное → сравнение → корзина → согласие на контактные данные → оформление одной покупки → имитация оплаты → работа менеджера → согласование доставки → обращение и ответ поддержки → ручная фиксация передачи/получения → финансовый пульт → повтор состава → выключенный промокод и отдельная активация → предпросмотр новой скидки → отдельное согласие на уведомление → подтверждённый тестовый остаток → один сигнал → отписка.

В финале: одна тестовая покупка, одна подтверждённая тестовая оплата, одно вручение, повторный состав в корзине. Промокод только выбран для следующего оформления, вторая покупка не создаётся.

## Воспроизведение записи

1. Поднять **новую** временную БД через `python3 tools/bot_demo.py --port 4175` отдельным процессом. Демо не читает production `.env` и не делает внешних платежей.
2. Установить build-time инструменты Playwright/Chromium и видеокодировщик. В текущей среде использованы Playwright 1.63.0, Chromium 152, локальный FFmpeg 7.0.2 из imageio-ffmpeg, Pillow 12.3.0 и numpy 2.4.6. Эти зависимости не добавляются в runtime бота.
3. `VIDEO_DRY=1 node tools/video/client_overview.cjs` — быстрая репетиция. После неё перезапустить демо с чистой временной БД.
4. `node tools/video/client_overview.cjs` — запись браузера. `VIDEO_WORK` задаёт каталог промежуточных файлов; по умолчанию `/home/user/.cache/bot-video`. `VIDEO_DEMO_URL` по умолчанию `http://127.0.0.1:4175`. `PLAYWRIGHT_EXECUTABLE_PATH` можно указать отдельно.
5. `python3 tools/video/render_client_overview.py --capture /путь/capture.json` — упаковка MP4. В текущем выпуске навигация ускорена в 1,2 раза и обрезаны начальные 0,75 секунды загрузки.

`client_overview.css` применяется только в контексте записи: укрупняет интерфейс и добавляет презентационные поля. CSP отключён только для внедрения этих аннотаций в изолированном recording browser; политика приложения не изменяется. Тексты ответов, цены, статусы и счётчики в UI не подменяются. Нажатия и команды действительно проходят через демо-контроллер и его БД.

Запись проверяет HTTP-ответы, отсутствие браузерных ошибок и итоговые бизнес-счётчики. Экспорт проверен полным декодированием видео и аудио, порядком MP4 atoms для fast-start и выборочными кадрами.

Промежуточные записи/аудио находятся в `.cache`; итоговые материалы — в игнорируемой папке `ui-checks/`. Не добавлять многомегабайтные видео в Git. Боевые настройки, каталог и код обработчиков для этого ролика не менялись. Commit/push/deploy не выполнялись.

## Короткая версия — 60 секунд

`ui-checks/client-overview/vorozhbitov-bot-demo-60s.mp4` — короткий монтаж для пересылки заказчику: ровно 60 секунд / 1500 кадров, 1920 × 1080, H.264/AAC, около 6 МБ.

Длинные формы и навигация убраны монтажом. Фрагменты приложения взяты из проверенной исходной записи; тексты, суммы, статусы и счётчики бота не подменяются. Укорочены только внешние поясняющие титры, вступление и финал. Звук — самостоятельная 60-секундная версия оригинального фонового сопровождения, без диктора.

Сборка: `python3 tools/video/render_client_short.py`. Нужны исходный `capture.json`/WebM от полного обзора и его `cover.jpg`. Промежуточные файлы остаются в `.cache`, готовый ролик и `short-video-report.json` — в игнорируемой `ui-checks/client-overview/`.

Короткая версия проверена полным декодированием аудио/видео, подсчётом 1500 кадров, выборочными кадрами и наличием MP4 fast-start. Полная версия 3:56 сохранена отдельно.

### Восстановленная минутная версия

После очистки временного окружения минутный монтаж восстановлен из проверенных ключевых кадров повторно выполненного сценария. Итог: `deliverables/vorozhbitov-bot-demo-60s.mp4` (60 секунд, H.264/AAC). Это монтаж настоящих экранов демо с титрами и музыкой, а не запись боевого Telegram. Файл вынесен из игнорируемого `ui-checks/` как запрошенный пользователем конечный результат.

Для такого восстановления предусмотрен `render_client_short.py --stills --capture .../capture.json --output deliverables`. Команды и обработчики выполняются сценарием `client_overview.cjs`, включая проверки итогового состояния. Промежуточные материалы остаются в `.cache`.
